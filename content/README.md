# How to edit the wording

Edit any of these files in a text editor (or Cursor). Change the words freely.

Keep these things as they are, so the page can be rebuilt without errors:
- The three lines at the very top between the `---` marks (title, color, and the short intro).
- Lines that start with `##` are section headings.
- A line that is only `[[chart]]`, `[[table]]`, or `[[sites]]` marks where a chart, grades table, or row of site tiles goes. Move it or delete it, but don't change what's inside the brackets.
- Lines in the "facts" block start with `- Label: text`.

When you're done, tell me and I'll rebuild the pages. You don't need to run anything.
